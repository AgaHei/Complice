# 🚀 Guide d'utilisation rapide - Complice

## 👦 Pour votre fils

### Lancer l'application
1. **Double-cliquez sur "🚀 Complice"** sur le Bureau
2. **Attendez** que la fenêtre noire affiche "✅ Complice est prêt !"
3. **L'application s'ouvre automatiquement** dans le navigateur
4. **Laissez la fenêtre noire ouverte** pendant l'utilisation

### Utiliser l'application
- **Page d'accueil** : Choisir entre Dialogue, Émotions ou Quiz
- **Dialogue** : Poser des questions sur l'autisme, les relations sociales
- **Émotions** : Générer des images pour comprendre les émotions
- **Quiz** : Tester ses connaissances sur les habiletés sociales

### Fermer l'application
- **Option 1** : Fermer la fenêtre noire (recommandé)
- **Option 2** : Double-cliquer sur "🛑 Arrêter Complice"

## 🔧 Résolution de problèmes

### L'application ne s'ouvre pas
1. Vérifier que **Docker Desktop** est ouvert et démarré
2. Attendre la fin du message "Initialisation de l'application"
3. Si problème persiste : fermer la fenêtre et relancer

### Le navigateur n'affiche rien
- Aller manuellement sur : **http://localhost:8501**
- Rafraîchir la page (F5)

### Message d'erreur Docker
- Ouvrir **Docker Desktop** depuis le menu Démarrer
- Attendre qu'il soit complètement démarré
- Relancer l'application

## ⚠️ Important
- **Ne pas fermer Docker Desktop** pendant l'utilisation
- **Laisser la fenêtre noire ouverte** = l'app fonctionne
- **Internet requis** pour la génération d'images
